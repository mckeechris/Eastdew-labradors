# Eastdew Labradors 2.0 — FINAL

Production-ready static Eastdew Labradors website.

## Source-of-truth rules applied
- The  Eastdew 2.0 visual pages are the design/content reference.
- Candy, Comet and Nova use their  real photography and  names.
- Each dog page presents three  photographs exactly once: one hero image plus two gallery images.
- Comet's show-ring photograph is a privacy crop made from Chris's supplied original; the people in the background have been removed while preserving Comet.
- The Puppy/Litters imagery may remain AI-generated where already approved.
- The approved Luna-with-puppy kennel artwork is retained.
- Old/incorrect Comet show-ring material is not included in the production asset set.
- No GitHub deployment is performed by this package.
